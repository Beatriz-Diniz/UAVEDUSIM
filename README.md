# UAVEDUSIM

#### Clone
```bash
git clone --recursive https://github.com/Beatriz-Diniz/UAVEDUSIM.git                                                            
```

Pacotes necessarios
```bash
sudo apt-get update
sudo apt-get install -y \
    ca-certificates \
    gnupg \
    gosu \
    lsb-release \
    software-properties-common \
    sudo \
    wget
```
Run docker

Apagar docker
sudo docker rm -f uavedusim-sim-uid1000
